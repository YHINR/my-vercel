# הודעות שלוחה - פריסה לוורסל

## מבנה הפרויקט
```
voicemail-app/
├── index.html          <- הדף הציבורי (בלי סודות בכלל)
├── api/
│   ├── verify-pin.js   <- בודק את קוד ה-PIN בצד שרת
│   ├── messages.js     <- מושך את רשימת ההודעות (הטוקן נשמר כאן)
│   └── audio.js        <- מזרים את קובצי האודיו (מסתיר את הטוקן)
```

## שלבי הפריסה

### 1. הרשמה לוורסל
היכנס ל-https://vercel.com והתחבר (אפשר עם GitHub, בחינם).

### 2. העלאת הקוד
הדרך הכי פשוטה:
- צור repository חדש וריק ב-GitHub.
- העלה אליו את כל תוכן התיקייה הזו (`index.html` והתיקייה `api`).
- בוורסל: "Add New Project" -> בחר את ה-repository -> "Deploy".

(אפשר גם עם ה-CLI: `npm i -g vercel` ואז `vercel` מתוך התיקייה, בלי GitHub בכלל.)

### 3. הגדרת המשתנים הסודיים (חשוב מאוד!)
בפאנל הפרויקט בוורסל:
`Settings -> Environment Variables`

הוסף שני משתנים:

| שם המשתנה     | ערך                                  |
|----------------|---------------------------------------|
| `CALL2ALL_TOKEN` | הטוקן שלך מ-call2all (זה שהיה גלוי בקוד) |
| `PIN_CODE`       | קוד ה-PIN שתרצה שאנשים יזינו (למשל 1234, או משהו אחר) |

אחרי הוספתם, לחץ **Redeploy** כדי שהם ייכנסו לתוקף.

### 4. זהו!
תקבל כתובת כמו:
```
https://your-project-name.vercel.app
```
זו הכתובת שאפשר לשלוח לכל מי שרוצה - הטוקן וה-PIN האמיתי לא מופיעים בשום מקום בקוד הציבורי.

## למה זה בטוח יותר?
- **הטוקן** של call2all נשמר רק כמשתנה סביבה בשרת של וורסל - לעולם לא נשלח לדפדפן.
- **קוד ה-PIN** נבדק בשרת (`api/verify-pin.js`) ולא בקוד ה-JS שרואים בדפדפן.
- **קובצי האודיו** מוזרמים דרך `api/audio.js` - כך שגם קישור ההשמעה עצמו לא חושף את הטוקן.

## הערה על אימות הטלפון
שלב אימות הטלפון (מול ה-Google Apps Script שלך) נשאר כפי שהיה - זו כבר בדיקה שמתבצעת בצד שרת, ואין שם סוד שנחשף.

## מגבלות התוכנית החינמית של וורסל
מספיק בהחלט לשימוש אישי/קטן: 100GB תעבורה בחודש, ללא הגבלת מספר פריסות.
